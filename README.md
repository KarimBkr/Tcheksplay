# ⚽ TCHEKSPLAY

**Application mobile sportive** type Kings League avec live, stats et social feed.

## 🚀 Quick Start

```bash
# Installation
npm install
npm run start

# Expo
expo start
```

## 📱 Tech Stack

- **React Native** + Expo SDK 52
- **Expo Router** v3 (navigation)
- **NativeWind** v4 (Tailwind)
- **TypeScript** (strict mode)
- **TanStack Query** v5 (cache)
- **Zod** (validation)
